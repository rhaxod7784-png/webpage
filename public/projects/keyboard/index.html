CREATIVE TOOL / EXPRESSION

Keyboard Canvas

글을 색으로 바꿀 때, 내가 쓴 말은 어떤 모습으로 남을까.

v1.0.0 · 배포 기록
이 프로젝트의 고민01 / 시작02 / 규칙03 / 되돌린 선택04 / 구현05 / 다음 질문
01 / ORIGIN

피아노 키보드에서 색깔의 글로

최초의 생각은 키를 누르면 순간적으로 반응하는 작은 키보드 습작에 가까웠습니다. 그런데 키를 누른 결과가 사라지는 대신 어떤 형태로 남는다면 어떨까 생각했습니다.

소리로 남기는 플레이어와 그림으로 남기는 도구, 두 방향이 생겼습니다. Keyboard Canvas는 그중 색과 이미지를 선택한 결과입니다.

내가 쓴 글의 색깔을 보고 싶다.

같은 규칙을 사용하더라도 사람마다 다른 단어와 문장을 쓰니 결과가 달라질 수 있습니다. 글을 10글자로 압축하려는 텐텐텐과 달리, 여기서는 더 많이 쓸수록 작품의 색과 밀도가 풍부해지는 방향을 원했습니다.

02 / RULES

무작위보다 먼저 정한 규칙

처음부터 화려한 그림만 얻으려면 색을 무작위로 배치하면 됩니다. 하지만 그러면 입력한 글과 이미지 사이의 연결이 약해집니다.

그래서 같은 문자에는 같은 색이라는 규칙을 먼저 선택했습니다. 한글 자모 분해, 영문·숫자·기호까지 확장했고, 공백도 표현의 일부가 될 수 있는지 고민했습니다. 비어 있음도 글의 일부이기 때문입니다.

초기 100×100 크기의 격자에서 입력 단위를 탐색했고, 이후 글의 길이와 기기 해상도에 맞춰 캔버스를 확장했습니다.

03 / TRIAL & ERROR

보기 좋은 그림과 규칙적인 그림

색의 분포와 영역을 바꾸면 결과가 더 화려해지기도 했지만, 입력과 그림의 관계가 흐려지기도 했습니다. 자음과 모음의 영역을 구분하거나 색 강도를 조절하는 실험도 거쳤습니다.

마음에 들지 않는 변경은 되돌렸습니다. 확대 방식, 색 규칙, 윤곽 표시를 수정하면서 새 오류가 생기기도 했습니다. 기획·개발 기록에는 성공한 버전뿐 아니라 왜 고쳤고, 왜 버렸는지에 관한 기록이 남아 있습니다.

04 / BUILT

현재 구현과 그 범위

v1.0.0 개발 기록에는 삼성 55종·아이폰 30종의 화면 해상도 설정, 문자 색상 규칙 카드 494개, 두 가지 생성 방식, PNG 저장, 네 언어 인터페이스가 포함되어 있습니다.

큰 입력을 처리하기 위한 렌더링 개선과 이미지 출력 테스트를 진행했고 Cloudflare Workers에 배포했습니다. 다만 AI 이미지 확장과 템플릿 가공은 앱 외부의 별도 작업으로, 앱의 내장 기능은 아닙니다.

05 / OPEN QUESTION

원문을 읽을 수 없어도 자기 글일까?

문자를 색으로 바꾸는 도구는 만들었습니다. 하지만 원문을 해독할 수 없는 그림에서도 사람들이 자기 표현을 느낄지는 아직 남은 질문입니다. 다른 사람의 결과를 보고 서로를 궁금해할지, 함께 만드는 캔버스가 재미있을지는 별개의 실험입니다.

지금 확인 가능한 것은 배포된 습작이며, 사회적 기능과 사용자 반응이 증명되었다고 주장하지 않습니다.
