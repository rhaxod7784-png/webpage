OBSERVATION / 01

은행나무 사건 개요

‘은행나무 암수 교체 사업’ 현수막을 계기로 시작된 CBZP의 하청 업무. 깅코트리 브레이커는 폿 브레이커의 두 번째 테마로 기획된 게임이다.

  1. 01
    사업 의뢰

    은행나무 암수 교체 사업이라는 설정 아래 CBZP가 관련 하청 업무를 맡는다.

  2. 02
    게임 전환

    기존 미로 추격전이 아닌, 두더지 잡기 형태의 짧은 반응형 게임을 만든다.

  3. 03
    목표

    냄새가 나기 전에 은행나무 열매를 잡아 점수를 얻는 구조다.

  4. 04
    표현

    폿 브레이커와 동일한 형식의 대문 그림, 4컷 만화, 게임 접속 화면을 테마별 콘텐츠로 구성한다.

감 과장 기록

제162호 본편에서 파생된 테마2다. 별도의 새 사건번호를 임의로 발급하지 않는다.

RULES / 02

확정된 게임 골격

플레이 방식은 두더지 게임형이다. 다음은 기획 대화에서 확인된 범위이며, 난이도별 수치·시간제한·득점 계산식은 확정 자료가 없어 추가하지 않았다.

01 / 대상

은행나무 열매

열매가 등장하면 냄새가 나기 전에 잡는 것이 플레이의 핵심이다.

02 / 조작

두더지 게임 방식

출현하는 대상을 빠르게 선택하는 반응형 조작을 기준으로 한다.

03 / 보상

점수

정해진 조건에 맞춰 열매를 잡으면 점수를 얻는다. 정확한 점수·감점 규칙은 미확정이다.

04 / 상태

설계 확정과 구현 구분

게임 콘셉트와 모듈화 방향은 확인됐다. 실제 서비스의 완성도와 공개 여부는 연결된 저장소에서 확인되지 않았다.

미확정: 레벨별 시간·난이도·점수표, 실제 은행나무 그래픽, 공개 게임 URL 및 테마2 QA 통과 여부.

DEVELOPMENT / 03

공통 엔진 · 테마 플러그인

폿 브레이커 코드를 복사해 별도 게임을 만드는 방식이 아니라, 기능을 클래스 단위로 분해하고 매개변수로 재조립하는 엔진 구조가 확정된 개발 방향이다.

공통 기능

입력 · 상태 · 화면 · 이벤트

두 게임에서 공유 가능한 기능을 기존 폿 브레이커 엔진의 모듈로 분리하고 재사용한다.

테마 플러그인

Ginkgo Tree Breaker

열매 출현, 포착, 냄새 발생과 점수 규칙 등 테마 전용 기능을 엔진 위에 추가하는 구상이다.

콘텐츠 형식

대문 · 4컷 만화 · 게임 진입

본편의 화면 진입 흐름과 동일한 콘텐츠 형식을 유지한다. 세계관 등장인물은 전면 얼굴을 노출하지 않는 제작 규칙을 따른다.

구현 확인

소스 검증 필요

연결된 potbreaker 저장소 main 트리에서 깅코 전용 파일이나 플러그인을 확인하지 못했다. 구현 완료라고 단정하지 않고 별도 검증 대상으로 기록한다.

기존 설계와의 경계

공통 엔진 재사용은 확정 요구다. 클래스 명칭, 매개변수 인터페이스 및 모듈 API는 실제 소스가 확인되기 전까지 임의 작성하지 않는다.
