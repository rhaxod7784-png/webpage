OPERATION / 01

작전 개요

기묘 대리가 플레이어, 크다 부장이 NPC로 맞서는 CBZP 사무실 미로 추격전. 2026년 11월 3일의 v1.1.1 확정 변경 요구를 기준으로 작성한 감사 기록이며, 실제 운영 배포 버전과 동일하다는 의미는 아니다.

  1. 01
    화분 수집

    노멀·하드·베리하드 모두 소지 화분 최대 3개. 필드 화분은 6개를 유지하며 수집 후 무작위 위치에 보충한다.

  2. 02
    공격과 충전

    화분은 자동 조준으로 투척되며, 화분을 수집했다고 명중이 보장되지는 않는다. 최대 3개를 충전하는 기믹과 스파크 연출을 설계 기준에 추가했다.

  3. 03
    추격·회피

    기묘와 크다 부장의 대시 간격은 각각 3초와 5초. 파티션 통과는 금지하며 크다 부장이 기묘에게 접촉하면 크다 승리로 판정한다.

  4. 04
    감 과장 개입

    감 과장은 이전보다 늦게 등장하는 대신 더 많은 화분을 뿌리는 방향으로 조정한다.

  5. 05
    승패 장면

    기묘가 이기면 크다 부장의 뚝배기가 깨지고, 크다가 이기면 기묘가 화분에 심기는 컷신을 사용한다.

감 과장의 여백 메모

확정 기획과 구현 결과를 혼동하지 말 것. 제457호 깅코트리 브레이커 문서에는 은행나무 열매 사건을 따로 보관한다.

RULES / 02

v1.1.1 기준 규칙

다음은 사용자 확정 설계 규칙이다. 현재 GitHub 기본 브랜치의 실행 코드 검증 결과나 실서비스 동작을 뜻하지 않는다.

01 / 체력과 이동

기묘 · 크다

기묘 체력 3, 크다 체력 5. 기묘 대시 3초, 크다 대시 5초. 파티션은 통과할 수 없다.

02 / 필드

화분 6개 유지

필드의 수집 화분은 6개를 유지하며 무작위로 재생성한다. 수집한 화분의 크기는 크다 부장 크기를 따른다.

03 / 투척

자동 조준 · 장애물

자동 조준은 60도 범위를 왕복하며 속도는 기존 대비 1/3. 투척 화분은 장애물을 최대 2개까지 돌파할 수 있다. 크다 부장은 화분 2개를 동시에 투척한다.

04 / 충전

최대 3개

소지 화분 최대 3개를 충전에 사용한다. 1개·2개·3개 충전 시 기묘 주변 스파크도 각각 1개·2개·3개로 표시한다.

유의: 난이도별 별도 체력 수치, 실제 명중 판정·랭킹 처리, 게임 시작 동작 등은 최신 빌드 대조 전까지 검증 완료로 표기하지 않는다.

DEVELOPMENT / 03

개발·배포·QA 기록

2026년 11월 3일 v184 배포 버전으로 롤백하고 v1.1.1 업데이트를 요청한 기록을 기준으로, 설계 기준과 저장소 검증 범위를 구분한다.

엔진 설계

Python 게임 기능의 클래스 모듈화

폿 브레이커를 기능별 엔진 모듈로 나누고, 매개변수와 테마별 플러그인으로 재조립하는 구조를 목표로 한다. 테마2도 같은 엔진을 재사용한다.

기존 저장소

Pyodide · Canvas · Cloudflare Workers

연결된 potbreaker GitHub 기본 브랜치의 README·웹 소스에는 여전히 v1.0.0 기준 설명이 남아 있다. 해당 소스가 v1.1.1을 반영한다는 근거는 확인되지 않았다.

배포 이력

Cloudflare v184 · 소스 일치 미확인

저장소의 deployments/potbreaker-v184.json에는 v184 100% 트래픽 복구 기록과 GitHub 소스 일치 여부 NOT_VERIFIED가 명시돼 있다. 현재 실제 서비스의 버전은 별도 확인이 필요하다.

QA 항목

시작 버튼 · 랭킹 · 돌아가기

게임 시작 불가, 랭킹 등록·처음으로 버튼 누락, 난이도별 화분 3개와 충전 효과, 장애물 관통 등은 최신 동작 검증이 필요하다.

상태 분리

설계 확정: v1.1.1 규칙. 저장소 구현 확인: 미완료. 서비스 배포 확인: 미완료. Android v0.16.0은 별도 보관본이다.
