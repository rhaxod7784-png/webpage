OPERATION / 01

작전 개요

기묘 대리가 플레이어로 출전하고 크다 부장은 추격 NPC로 맞서는 1인용 브라우저 게임. 미로에서 화분을 확보하고 상대의 체력을 먼저 소진시키는 작전이다.

  1. 01
    난이도 선택

    시작 화면에서 노멀·하드·베리하드 중 하나를 선택한다.

  2. 02
    기묘 출전

    기묘의 체력은 3이며 시작 시 화분 탄약은 0개다. 난이도에 따라 보유 가능한 화분 수가 달라진다.

  3. 03
    화분 확보와 회피

    필드의 화분을 모으고 움직이는 파티션 사이에서 크다 부장의 공격을 피한다. 대시와 투척은 각각 재사용 대기시간을 둔다.

  4. 04
    감 과장 개입

    감 과장은 일정 간격으로 등장해 특수 화분을 투하한다. 효과에는 체력 회복·감소, 탄약 보충, 필드 화분 초기화가 포함된다.

  5. 05
    승패 기록

    승리 또는 패배 장면을 표시하고, 웹 버전은 경기 기록과 랭킹 기능에 필요한 데이터를 처리한다.

감 과장의 여백 메모

게임 규칙은 실행 코드와 안내 문구를 함께 대조해야 한다. 현재 난이도별 크다 부장 체력 표기가 서로 달라 확인 대상으로 남겼다.

RULES / 02

현장 규칙과 확인된 불일치

아래 수치는 폿브레이커 RE v1.0.97 저장소의 게임 구현 파일을 기준으로 기록했다.

01 / 기묘

플레이어

기묘의 체력은 3. 시작 탄약은 0개이며, 노멀에서 보유 한도는 3개, 하드와 베리하드에서는 2개다. 대시 재사용 대기시간은 3초다.

02 / 크다 부장

추격 NPC

코드상 체력은 노멀 5, 하드 7, 베리하드 10으로 설정돼 있다. 맵 전체에서 기묘와 화분을 추적하며, 대시 재사용 대기시간은 5초다.

03 / 필드 화분

수집·특수 효과

필드에는 일반 탄약 화분 4개와 별도 회복 화분 1개를 유지한다. 감 과장 투하 화분은 회복, 피해, 탄약 보충, 필드 초기화 중 하나의 효과를 가진다.

04 / 미로

이동과 파티션

게임판은 19×11 격자다. 기묘는 상·하·좌·우 한 칸씩 이동하며, 파티션은 이동 경로를 막을 수 있다. 대시와 파티션 이동은 각자 별도의 시간 규칙을 가진다.

확인 필요: 게임 구현 코드는 크다 부장 체력을 5·7·10으로 설정하지만, 공개 게임 안내 페이지에는 3·5·7로 적혀 있다. 두 곳의 기준을 통일하기 전까지 난이도 밸런스가 정리됐다고 볼 수 없다.

DEVELOPMENT / 03

개발·운영 기록

브라우저판 저장소의 현재 표시 버전은 v1.0.97이다. 게임 규칙과 화면은 웹 소스에서 Worker 번들로 생성된다.

게임 규칙

Python · Pyodide / WebAssembly

게임 엔진을 브라우저 안에서 실행한다.

화면 구성

HTML · CSS · Canvas

게임판과 캐릭터, 터치 조작, 안내 화면을 표시한다.

웹 서비스

Cloudflare Workers · D1

Worker가 페이지와 API를 제공하고 D1이 방문·경기·랭킹 데이터를 저장한다.

검색·광고

robots.txt · sitemap · ads.txt · AdSense

크롤링용 경로와 광고 설정을 추가해 점검 중이다. Search Console에서 사이트맵이 HTML로 읽힌다는 오류가 보고되어 텍스트 사이트맵 경로를 추가했다. 운영 응답과 Search Console 재처리는 아직 확인되지 않았다.

QA 상태

모바일 입력과 게임 화면은 계속 조정 중이다. 안내 페이지와 실행 코드의 난이도별 체력 값이 일치하지 않아 배포 기준을 다시 대조해야 한다. Android 앱 v0.16.0은 별도 제품으로 관리한다.
