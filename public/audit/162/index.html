OPERATION / 01

작전 개요

CBZP 인턴 고양이 기묘와 크다 부장의 미로 추격전. 화분을 확보해 상대를 맞히고, 벽을 넘어 작전 구역을 빠져나간다.

  1. 01
    작전 구역 진입

    기묘는 미로 모서리에서, 크다 부장은 중앙에서 경기를 시작한다.

  2. 02
    화분 확보

    바닥의 화분을 주워 투척 준비를 한다. 하나를 가져가면 빈자리에 새 화분이 보충된다.

  3. 03
    추격과 돌파

    기묘는 크다 부장을 살피며 움직이고, 크다 부장은 시야와 화분을 이용해 추격한다.

  4. 04
    감 과장 출동

    감 과장 얼굴 아이콘이 작전에 개입하면 무작위 화분 폭격이 시작된다.

  5. 05
    뚝배기 파손 사건

    기묘 대리가 크다 부장의 뚝배기를 다섯 번이나 깨뜨렸다. 감사 기록에는 파손 횟수 5회로 남긴다.

감 과장의 여백 메모

벽 너머가 안전지대인지는 아직 확인되지 않았다. 화분을 든 부장님이 따라오지 못할 거라는 보장도 없다.

RULES / 02

현장 규칙과 증거

보관된 POT BREAKER RE 웹게임 안내를 기준으로 핵심 규칙을 정리했다.

01 / 기묘

벽 넘기

맵 전체를 확인할 수 있다. 벽 넘기 횟수는 5초마다 충전되며 최대 3회까지 쌓인다. 화분이 없어도 넘을 수 있다.

02 / 크다 부장

시야와 돌진

정면 중심의 제한된 시야로 추격한다. 화분을 가지고 있으면 벽을 최대 3칸 돌파할 수 있고, 사용 후 재사용 대기시간이 있다.

03 / 화분

주워서 던지기

기묘는 화분 1개, 크다 부장은 최대 2개까지 소지한다. 획득 가능한 화분은 맵에 3개가 유지된다.

04 / 접근 경보

딸랑딸랑

기묘가 크다 부장에게 가까워지면 소리로 알린다. 경보는 방향을 알려주지 않는다.

※ 세부 수치와 조작감은 개발 중 조정될 수 있다. 설명은 보관 중인 웹 버전 안내 기준이다.

DEVELOPMENT / 03

개발 기록

기존 POT BREAKER Android 프로젝트를 유지하면서, CBZP 세계관의 새 싱글 플레이 미로 추격전을 웹 버전으로 구성했다.

게임 화면

HTML Canvas · JavaScript

미로와 캐릭터, 입력 및 장면을 브라우저에 표시한다.

게임 규칙

Python · Pyodide / WebAssembly

브라우저 안에서 게임 상태와 추격 규칙을 실행한다.

웹 제공

Cloudflare Workers

정적 게임 화면을 전달하며 별도 Python 서버는 실행하지 않는다.

모바일

가로 화면 · 터치 조작

휴대폰 가로 화면에 맞춘 플레이와 화면 터치 조작을 제공한다.

기록의 범위

이 서류는 POT BREAKER RE : CBZP 웹게임을 다룬다. 기존 Android 앱은 별도 기준의 POT BREAKER v0.16.0이다.
