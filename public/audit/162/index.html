OPERATION / 01

작전 개요

CBZP 인턴 고양이 기묘와 크다 부장의 미로 추격전. 화분을 확보해 상대를 맞히고, 승리할 때까지 추격을 버틴다.

  1. 01
    작전 구역 진입

    기묘는 미로 모서리에서, 크다 부장은 중앙에서 경기를 시작한다.

  2. 02
    화분 확보

    바닥에는 획득 가능한 화분 6개가 유지된다. 던진 화분은 필드 수를 늘리지 않는다.

  3. 03
    추격과 돌파

    기묘는 크다 부장을 살피며 움직이고, 크다 부장은 시야와 화분을 이용해 추격한다.

  4. 04
    감 과장 출동

    감 과장은 경기 시작 2.5초 뒤 등장한다. 14초 간격으로 돌아와 4.2초 동안 0.6초 간격으로 화분을 투하한다.

  5. 05
    뚝배기 파손 사건

    기묘 대리가 크다 부장의 뚝배기를 다섯 번이나 깨뜨렸다. 감사 기록에는 파손 횟수 5회로 남긴다.

감 과장의 여백 메모

크다 부장님은 화분을 최대 다섯 개까지 소지한다. 감 과장님은 이 사실을 조용히 기록했다.

RULES / 02

현장 규칙과 증거

보관된 POT BREAKER RE 웹게임 안내를 기준으로 핵심 규칙을 정리했다.

01 / 기묘

기묘의 이동

체력 3. 일반 이동 간격 0.105초, 대시 이동 간격 0.09초. 3칸 대시는 3초마다 충전된다. 모바일 조이스틱은 8방향을 지원하며, 대각선 이동 속도를 보정한다.

02 / 크다 부장

크다 부장

체력 5. 시야 제한 없이 기묘와 화분 위치를 추적한다. 화분은 최대 5개까지 소지하며, 대시 재사용 대기시간은 5초다. 보스 화분 투사체는 초당 6.4칸 이동한다.

03 / 화분

화분과 투척

기묘는 화분 1개, 크다 부장은 최대 5개를 소지한다. 필드에는 화분 6개가 유지된다. 기묘의 투사체는 초당 9.4칸, 크다 부장의 투사체는 초당 6.4칸 이동한다.

04 / 감 과장

화분 폭격

첫 출현은 2.5초 후, 재등장은 14초 간격이다. 4.2초 동안 비행하며 0.6초마다 ±30도 범위로 화분을 투하한다.

※ 수치와 조작 설명은 POT BREAKER RE v1.0.12의 웹 게임 소스와 변경 기록을 기준으로 했다.

DEVELOPMENT / 03

개발 기록

기존 Android 앱을 유지하면서, CBZP 세계관의 싱글 플레이 미로 추격전을 웹 버전으로 구성했다. 이 기록은 POT BREAKER RE v1.0.12 기준이다.

게임 화면

HTML Canvas · JavaScript

미로와 캐릭터, 입력 및 장면을 브라우저에 표시한다.

게임 규칙

Python · Pyodide / WebAssembly

브라우저 안에서 게임 상태와 추격 규칙을 실행한다.

웹 제공

Cloudflare Workers

정적 게임 화면을 전달하며 별도 Python 서버는 실행하지 않는다.

모바일

모바일 조작

가로 화면에서 8방향 조이스틱으로 이동한다. 대각선 속도는 보정되며, 던지기 터치 영역은 최소 112 × 112 CSS px다.

기록의 범위

이 서류는 POT BREAKER RE : CBZP 웹게임을 다룬다. 기존 Android 앱은 별도 기준의 POT BREAKER v0.16.0이다.
