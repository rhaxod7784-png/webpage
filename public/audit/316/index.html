SERVICE / 02

서비스 조사 · 테마 확장

대전의 기묘한 여행은 기준점 주변을 100m씩 넓히며 장소를 찾는 서비스다. 장소 추천에 이어 주차장 안내를 테마2로 개발 중이다.

01 / 테마1

주변 장소 추천

최초 100m 이내에서 카테고리별 최대 10곳을 추천하고 100m 단위로 탐색 범위를 확장한다. 상한은 5km다.

02 / 목록·지도

P1 모바일 개선

목록·지도 전환 후에도 이전·다음 100m 및 다시 추천 기능을 유지한다. 지도는 터치·마우스 이동을 잠그되 다음 100m 버튼으로만 범위를 조절하도록 요구했다.

03 / 테마2

대전 주차장 안내

목적지 주변 유·무료 주차장을 근접 순으로 탐색한다. 기준점에서 0~500m를 시작 범위로 삼고 이후 100m씩 확장한다. 실시간 잔여면수는 제공되는 주차장에 한해 표시한다.

04 / 테마3 후보

전국 축제지도

지역축제와 음악·공연 등 축제를 전국 범위로 탐색하는 후보 기획. 구현·배포 완료 기능으로 표기하지 않는다.

상태 구분: 테마1은 배포·개선 중, 테마2는 주차장 API 정보 보강 및 QA 중, 테마3는 후보 기획 단계다. 지도 화살표+장소명, 주차요금·주차면수 노출 등 최신 QA 결과는 아직 확정하지 않았다.

DEVELOPMENT / 03

개발·API·QA 기록

초기 MVP, 현재 서비스 구조, 2026년 11월 P1·테마2 개선 요청을 구분해 기록한다.

초기 MVP

Python · FastAPI · SQLite · Leaflet

위치 기반 추천, 지도 표현과 사용자 행동 이벤트를 검증하던 초기 구조.

공개 서비스

JavaScript · Cloudflare Workers · D1

장소 데이터 제공, 추천 요청, 상세 진입·내비게이션 클릭 로깅을 담당하는 웹 구조.

주차장 데이터

대전 공공데이터 API 연동·보강

기존 /6300000/pis 외에 GetPakpListService1 및 /6300000/openapi/rest2 두 API를 추가 확보하여 주차면수·요금·상세정보 보강을 요청했다. 필드별 응답과 운영 반영은 검증 전이다.

지도·모듈

Leaflet · 공통 상세서사 페이지

지도 재표시·컨테이너 크기 계산, 모바일 2열 버튼 및 텍스트 넘침을 QA한다. 장소·주차장 정보는 별도 임시 화면 대신 기존 상세서사 모듈 재사용을 요구했다.

운영 확인

실시간 데이터 갱신 · 표기 일관성

실시간 잔여면수는 최초 1회 조회 후 1분 주기 갱신. 미제공·조회 실패는 ‘실시간 정보 없음’, 만차는 빨간색으로 표기하도록 요구했다. 무료·유료 구분과 기본/추가요금, 총면수 누락은 QA 대상이다.

감 과장의 검증 메모

두 보강 API를 확보한 사실과 실제 응답 필드가 채워져 사용자 화면에 노출되는 것은 별개다. 무료 주차장 누락, 내비 목적지 누락, 지도 미표시, 응답 지연은 해결 여부를 검증해야 한다.
