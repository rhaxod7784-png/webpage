OBSERVATION / 01

관찰 경위

어느 평일, 기묘 대리의 외근 중 발생한 사건.

  1. 01
    외근 중

    기묘 대리는 회사 외근을 땡땡이치고 점심도 먹지 않은 채 성심당에서 웨이팅을 한다.

  2. 02
    빵 구매

    기묘 대리는 빵을 잔뜩 구매한다.

  3. 03
    연락 확인

    빵을 사고 나니 크다부장에게서 연락이 잔뜩 와 있다.

  4. 04
    골목으로 이동

    기묘 대리는 “28! 아 몰라” 하고 맛있는 것을 먹으러 골목으로 향한다.

감 과장의 여백 메모

기묘 대리는 모르고 있다. 그런데 당신은 지금 이 기록을 보고 있다.

CBZP · 감사원기록 / 02

SERVICE / 02

대상 서비스 조사

대전의 기묘한 여행은 장소를 선택하고 다음 이동을 탐색하는 웹서비스다.

열람자에게: 이 서류가 궁금해서 넘어왔다면 조사 목적은 달성한 셈이다.

01 / 위치

출발 지점

위치 접근을 통해 현재 위치를 기준으로 장소를 탐색한다.

02 / 분류

카테고리 선택

하고 싶은 활동의 카테고리를 선택한다.

03 / 추천

가까운 장소

설계상 처음 100m 내 카테고리별 최대 10곳을 보여주고, 필요하면 탐색 범위를 넓힌다.

04 / 이동

상세와 길찾기

장소 정보와 이야기를 확인하고 외부 지도 앱으로 이동한다.

※ 추천 거리와 노출 건수는 초기 기획에 기록된 기준이며, 실제 운영 설정과는 차이가 있을 수 있다.

DEVELOPMENT / 03

개발 기록

초기 실험과 공개 서비스의 기술 구성을 구분해 기록한다.

초기 MVP

Python · FastAPI · SQLite · JSON

추천 요청과 사용자 행동 이벤트를 다루고, 장소 정보를 읽는 초기 구조.

공개 서비스

JavaScript · Cloudflare Workers · D1

추천 요청 처리, 장소 데이터 제공 및 사용자 행동 기록.

프론트엔드

HTML · CSS · JavaScript

카테고리, 장소 추천 카드, 상세 화면 및 지도 연결.

검증

Python unittest · Node.js · Playwright

거리 계산, 추천 빈 구간, GPS 및 모바일 동작의 테스트 기록.

기록의 범위
